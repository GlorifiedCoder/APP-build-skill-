# Workflow 05 — Testing and Audit

## Steps
1. Map requirements to tests.
2. Review test coverage for business rules and critical journeys.
3. Execute unit, integration, contract, UI and E2E tests as appropriate.
4. Test permissions, invalid input, offline, timeout, retry and recovery.
5. Test representative devices, OS versions, screen sizes and accessibility settings.
6. Run static analysis and dependency/security scans.
7. Review performance budgets and crash/error signals.
8. Record exact commands, versions, environment, results and evidence.
9. Triage defects by severity and retest fixes.
10. Run regression tests.

## Gate
Critical and high-severity unresolved defects block release unless an authorized risk acceptance is explicitly recorded.
