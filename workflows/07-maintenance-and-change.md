# Workflow 07 — Maintenance and Change

## Steps
1. Triage user feedback, incidents, defects and metrics.
2. Reproduce and identify root cause.
3. Assess user, data, security and compatibility impact.
4. Update requirements/decision records if behavior changes.
5. Plan a bounded change.
6. Implement and test.
7. Run regression and deployment checks.
8. Release through the approved gate.
9. Update known issues, changelog and operational docs.

Never patch production blindly without understanding impact and rollback options.
