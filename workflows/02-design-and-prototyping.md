# Workflow 02 — Design and Prototyping

## Steps
1. Review approved PRD and user journeys.
2. Define information architecture and navigation.
3. Define design principles, tokens and component behavior.
4. Specify every MVP screen and its states.
5. Include accessibility, localization, dynamic text and adaptive layouts.
6. Create or inspect design artifacts if tools are available.
7. Map each screen interaction to a requirement and data/API dependency.
8. Review critical journeys and revise.

## Approval gate
Obtain approval for navigation, core flows and design direction before implementing a large UI surface.

## Outputs
Design system, screen specs, component inventory, interaction map and approved references.
