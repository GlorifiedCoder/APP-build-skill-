# Workflow 06 — Staging and Release

## Steps
1. Confirm approved scope and release candidate.
2. Verify reproducible build and signing configuration.
3. Verify secrets and environment configuration.
4. Back up data and validate restore procedure where applicable.
5. Apply reviewed, backward-compatible migrations where possible.
6. Deploy to staging.
7. Run smoke, critical journey, integration and rollback tests.
8. Review security, monitoring, alerting and support readiness.
9. Present release report and risks to the user.
10. Obtain explicit production approval.
11. Deploy using the approved procedure.
12. Verify health and monitor the release window.

## Prohibited
No production deployment, app-store submission or destructive production migration without explicit approval.
