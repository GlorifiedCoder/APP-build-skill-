# Mobile Release Checklist

- [ ] App ID / bundle ID and version are correct.
- [ ] Release build is reproducible.
- [ ] Signing keys are securely managed.
- [ ] Debug endpoints and test credentials are removed.
- [ ] Permissions are necessary, disclosed and correctly handled.
- [ ] Privacy policy and store declarations are reviewed.
- [ ] Crash reporting and analytics respect consent/privacy.
- [ ] Offline, denied-permission and lifecycle behavior tested.
- [ ] Accessibility and supported screen sizes tested.
- [ ] Deep links and notifications tested.
- [ ] API compatibility and backend rollout verified.
- [ ] Data migration and rollback/forward-fix plan reviewed.
- [ ] Store assets and release notes prepared.
- [ ] Staged rollout and monitoring plan approved.
- [ ] Explicit production/store submission approval recorded.
