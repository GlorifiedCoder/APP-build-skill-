# Skill: Devops Release

## When to use
Use for CI/CD, build, staging, production and operational readiness.

## Required inputs
- Relevant project brief and approved specifications.
- Current repository state and related tests.
- Applicable architecture, security and design rules.

## Workflow
1. Inspect build and environment configuration.
2. Separate local, CI, staging and production secrets.
3. Automate format, lint, test, build and security checks.
4. Produce reproducible signed artifacts.
5. Define deployment, migration, rollback and smoke-test steps.
6. Verify monitoring, alerting and backups.
7. Require explicit user approval before production deployment.

## Expected outputs
Pipeline, deployment runbook, release checklist and verification report.

## Quality rules
- Do not invent facts, test results or approvals.
- Cite external research where used.
- Identify assumptions and unresolved risks.
- Respect `AGENTS.md` approval requirements.
- Update project documentation when the outcome changes the source of truth.
