# Skill: Implementation

## When to use
Use for bounded feature implementation.

## Required inputs
- Relevant project brief and approved specifications.
- Current repository state and related tests.
- Applicable architecture, security and design rules.

## Workflow
1. Read the feature specification and relevant code.
2. Inspect repository state and avoid unrelated changes.
3. Plan a small vertical slice.
4. Implement production behavior, not placeholders.
5. Add unit/integration tests.
6. Run checks and inspect the diff.
7. Update documentation and task status.
8. Report exact evidence and limitations.

## Expected outputs
Working code, tests, documentation updates and completion report.

## Quality rules
- Do not invent facts, test results or approvals.
- Cite external research where used.
- Identify assumptions and unresolved risks.
- Respect `AGENTS.md` approval requirements.
- Update project documentation when the outcome changes the source of truth.
