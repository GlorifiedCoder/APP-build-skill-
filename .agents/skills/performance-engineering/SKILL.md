# Skill: Performance Engineering

## When to use
Use when profiling startup, UI, network, battery or resource usage.

## Required inputs
- Relevant project brief and approved specifications.
- Current repository state and related tests.
- Applicable architecture, security and design rules.

## Workflow
1. Define user-visible performance budgets.
2. Establish reproducible baseline and device/network conditions.
3. Profile before optimizing.
4. Identify bottlenecks with evidence.
5. Make targeted changes.
6. Re-run comparable measurements.
7. Document trade-offs and regressions.

## Expected outputs
Performance report, baseline, findings and verified improvements.

## Quality rules
- Do not invent facts, test results or approvals.
- Cite external research where used.
- Identify assumptions and unresolved risks.
- Respect `AGENTS.md` approval requirements.
- Update project documentation when the outcome changes the source of truth.
