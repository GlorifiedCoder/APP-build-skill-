# Definition of Done

A feature is done only when all applicable items are satisfied:

- [ ] Approved specification and acceptance criteria exist.
- [ ] Implementation is integrated; no production placeholder remains.
- [ ] Loading, empty, success, error and offline states are handled where relevant.
- [ ] Authorization and validation are enforced at the correct boundary.
- [ ] Unit and integration tests are added and executed.
- [ ] Relevant UI/API/E2E regression tests are executed.
- [ ] Accessibility and responsive/adaptive behavior are checked.
- [ ] Logs contain no sensitive data.
- [ ] Build, lint and static analysis pass.
- [ ] Documentation and feature inventory are updated.
- [ ] Known gaps are disclosed.
- [ ] Required reviewer approval is recorded.
