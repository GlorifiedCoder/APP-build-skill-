# CI/CD

## Pipeline stages
1. Checkout and dependency setup.
2. Secret and configuration checks.
3. Format and lint.
4. Static analysis.
5. Unit tests.
6. Integration/contract tests.
7. Build.
8. Dependency/security scans.
9. Artifact signing/provenance.
10. Staging deployment after approval.
11. Production deployment only after explicit approval.
