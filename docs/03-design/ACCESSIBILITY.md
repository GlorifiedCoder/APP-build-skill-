# Accessibility Requirements

Target applicable platform accessibility guidance and WCAG 2.2 AA for relevant web content.

- Screen reader semantics and labels.
- Logical focus and navigation order.
- Text scaling and display size.
- Color contrast; never communicate status by color alone.
- Touch target sizing.
- Reduced motion.
- Captions/transcripts for media where relevant.
- Accessible authentication and error recovery.
- Manual assistive-technology testing.

Record platform, device, OS version, assistive technology and result.
